=== 3. Операция < (Vector < Vector) ===
A < B : 1   (1,2,3 и 1,2,5: 3 < 5 -> истина)
B < A : 0   (5 > 3 -> ложь)
A < D : 0   (все пары равны -> ложь)
A < C : 0   (в C элементы закончились -> ложь)
C < A : 0   (в C элементы закончились -> ложь)
A < F : 1   (1 < 5 -> истина)

=== 4. Конструктор копирования и конструктор перемещения ===
Создаем копию: Vector copy(A);
  [Vector(const Vector&) - КОПИРОВАНИЕ n=3]
  A    = 3: (1, 2, 3)
  copy = 3: (1, 2, 3)
  Буфер у copy тот же, что у A? нет (память выделена заново)
  A после копирования: 3: (1, 2, 3) (не изменился)
Перемещаем: Vector moved(std::move(copy));
  [Vector(Vector&&) - ПЕРЕМЕЩЕНИЕ n=3]
  moved = 3: (1, 2, 3)
  copy  = 0: () (исходный объект стал пустым)
  Буфер у moved тот же, что был у copy? да (элементы не копировались)
Выход из блока - вызовутся деструкторы moved и copy:
  [~Vector() n=3]
  [~Vector() n=0]

=== 5. Присваивание с копированием и с перемещением ===
  [Vector()]
Присваивание с копированием: X = B;
  [operator=(const Vector&) - КОПИРОВАНИЕ]
  X = 3: (1, 2, 5),  B = 3: (1, 2, 5) (B не изменился)
  Буфер у X тот же, что у B? нет (выполнено копирование элементов)
  [Vector()]
Присваивание с перемещением: Y = std::move(X);
  [operator=(Vector&&) - ПЕРЕМЕЩЕНИЕ]
  Y = 3: (1, 2, 5)
  X = 0: () (исходный вектор стал пустым)
  Буфер у Y тот же, что был у X? да (элементы не копировались)
